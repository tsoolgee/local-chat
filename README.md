# צ'אט מקומי

צ'אט בסגנון ChatGPT שרץ כולו אצלכם במחשב, בלי אינטרנט ובלי כרטיס גרפי.
בוחרים מודל, מורידים אותו מתוך התוכנה, ומדברים. אפשר גם ליצור תמונות.

## מה יש בפנים

- ממשק מודרני בעברית: שיחות שנשמרות, חיפוש, הצמדה, שינוי שם, מצב כהה/בהיר
- תשובות שמופיעות תוך כדי כתיבה, עם Markdown, טבלאות והדגשת קוד
- עצירה, תשובה חדשה, עריכת הודעה ושליחה מחדש, העתקה
- **הורדת מודלים מתוך התוכנה**: רשימה מומלצת או כל קישור מ-Hugging Face, עם המשך הורדה אחרי ניתוק
- תצוגת "מחשבות" למודלים חושבים
- צירוף תמונות למודלים שרואים תמונות
- **יצירת תמונות** עם SD-Turbo, SDXL-Turbo, Z-Image ועוד. תיאור בעברית מתורגם אוטומטית לאנגלית בעזרת מודל השיחה
- נייד לגמרי: השיחות, ההגדרות והתמונות נשמרים בתיקייה `נתונים` שליד התוכנה

## התקנה

1. מורידים את `LocalChat-win-x64.zip` מדף ה-[Releases](../../releases/latest) ופורסים לתיקייה.
2. מפעילים את `LocalChat.exe`.
3. לוחצים **הורדת מודלים** ובוחרים מודל. בסוף ההורדה הוא נטען לבד.

הצ'אט נפתח בחלון משלו (דרך Edge או Chrome שכבר מותקנים). סגירת החלון סוגרת את התוכנה ומשחררת את הזיכרון.
כשהתוכנה רצה יש לה אייקון ליד השעון.

```
LocalChat\
├─ LocalChat.exe
├─ engine\            מנוע השיחה (llama.cpp) ומנוע התמונות (stable-diffusion.cpp)
├─ מודלים\            מודלי שיחה (כל מודל יכול לשבת בתיקייה משלו)
│  └─ תמונות\         מודלי תמונות
└─ נתונים\            נוצר אוטומטית: שיחות, הגדרות, תמונות
```

## מדריך מודלים

### מה זה בכלל "מודל"?

מודל הוא קובץ גדול (בין 1 ל-25 ג'יגה) שמכיל את ה"מוח" שעונה לכם. התוכנה היא רק המעטפת:
היא טוענת את המודל לזיכרון ומדברת איתו. מודל אחר = אישיות, ידע ומהירות אחרים.
אפשר להחזיק כמה מודלים ולעבור ביניהם מהתפריט שבראש המסך.

### המספרים בשם המודל

| מה כתוב | מה זה אומר |
| --- | --- |
| **2B / 9B / 12B** | מספר הפרמטרים במיליארדים (B = Billion). יותר = חכם יותר, אבל איטי יותר וצורך יותר זיכרון |
| **35B-A3B** | מודל **MoE** (תערובת מומחים): גודל כולל 35B, אבל בכל מילה פועלים רק 3B. חכם כמו מודל גדול, מהיר כמו מודל קטן. צריך הרבה זיכרון |
| **Q4_K_M** | רמת ה"דחיסה" (קוונטיזציה). Q4 = 4 ביט למספר, כמעט בלי פגיעה באיכות ובערך רבע מהגודל המקורי. **זו הבחירה המומלצת** |
| Q8_0 / F16 | פחות דחוס: קצת יותר מדויק, פי 2 עד 4 יותר גדול ואיטי |
| Q2 / Q3 | דחוס מאוד: קטן ומהיר, אבל המודל מתחיל "לטפש" |
| **GGUF** | פורמט הקובץ שהתוכנה קוראת. מחפשים ב-Hugging Face מודל עם המילה GGUF בשם |
| **Instruct / it** | גרסה שאומנה לשיחה. תמיד לבחור בה, ולא בגרסת Base |
| **mmproj** | קובץ נלווה שנותן למודל "עיניים" (הבנת תמונות). שמים אותו באותה תיקייה עם המודל |

### כמה זיכרון צריך?

כלל אצבע: **גודל הקובץ + 1 עד 3GB** (בשביל "זיכרון השיחה" ומערכת ההפעלה).
במחשב עם 32GB אפשר להריץ כל מודל עד בערך 24GB. במחשב עם 8GB כדאי להישאר עם מודלים של 2B עד 4B.

בלי כרטיס גרפי המהירות תלויה בעיקר במהירות הזיכרון (RAM). הערכה גסה למחשב ביתי:

| גודל קובץ | מהירות כתיבה משוערת |
| --- | --- |
| 1-3GB | מהיר מאוד, 15 עד 30 מילים בשנייה |
| 5-7GB | נוח, 5 עד 10 מילים בשנייה |
| 15-22GB (MoE) | 6 עד 12 מילים בשנייה, תלוי במודל |
| 15GB ומעלה (לא MoE) | איטי, 1 עד 3 מילים בשנייה |

### מודלי שיחה מומלצים (זמינים להורדה מתוך התוכנה)

| מודל | גודל | זיכרון | מתאים ל... |
| --- | --- | --- | --- |
| Qwen3.5 2B | 1.3GB | 3GB+ | מחשב חלש, שאלות פשוטות |
| Qwen3.5 4B | 2.7GB | 5GB+ | מחשב עם 8GB, שימוש יומיומי |
| Gemma 4 E4B | 5.0GB | 7GB+ | עברית טובה, מהיר |
| **Qwen3.5 9B** | 5.7GB | 9GB+ | **ההמלצה להתחלה**: חכם, טוב בקוד ובחשבון, יודע "לחשוב" |
| **Gemma 4 12B** | 7.1GB | 11GB+ | **עברית מצוינת**, ניסוח, סיכום ותרגום |
| DictaLM 3.0 12B | 7.5GB | 11GB+ | מודל עברי של מכון דיקטה |
| Gemma 4 26B-A4B | 17GB | 20GB+ | MoE: חכם מאוד ועדיין זריז, עברית טובה |
| Qwen3.5 35B-A3B | 22GB | 26GB+ | MoE: החכם ביותר שרץ טוב על 32GB |

**איך לבחור?** במחשב עם 32GB: להתחיל ב-**Qwen3.5 9B** או ב-**Gemma 4 12B**. אם הם טובים ורוצים יותר חוכמה, לנסות את **Qwen3.5 35B-A3B**.
לכתיבה בעברית Gemma בדרך כלל טבעי יותר. לקוד, חשבון והיגיון, Qwen.

### מודלים "חושבים"

מודלים כמו Qwen3.5 כותבים קודם "מחשבות" ורק אחר כך את התשובה. התוכנה מציגה את המחשבות בתיבה מקופלת.
התשובות טובות יותר בשאלות קשות, אבל לוקח יותר זמן עד שהתשובה מתחילה.

### "גודל הקשר" (בהגדרות)

כמה מהשיחה המודל זוכר, נמדד בטוקנים (מילה בעברית היא בערך 2 עד 3 טוקנים).
ברירת המחדל, 8,192, מספיקה לשיחה ארוכה. ערך גבוה יותר צורך יותר זיכרון ומאט קצת.
כשהשיחה ארוכה מדי, התוכנה משמיטה את ההודעות הכי ישנות.

### מודלי תמונות

| מודל | גודל | זמן לתמונה (מעבד) | הערה |
| --- | --- | --- | --- |
| **SD-Turbo** | 2.0GB | כדקה | הכי מהיר, 512×512, צעד אחד. מומלץ להתחלה |
| SDXL-Turbo | 4.1GB | 1-2 דקות | יותר פרטים ואיכות |
| Z-Image Turbo | 7.9GB | כמה דקות | האיכותי ביותר, מבין תיאורים מורכבים |

- מודלי תמונות מבינים בעיקר **אנגלית**. אם מודל שיחה טעון, תיאור בעברית מתורגם אוטומטית (אפשר לכבות בהגדרות).
- **צעדים**: יותר צעדים = יותר איכות ויותר זמן. למודלי Turbo מספיקים 1 עד 8, ובאוטומטי התוכנה בוחרת לבד.
- **גודל**: תמונה בגודל 1024×1024 לוקחת בערך פי 4 זמן מ-512×512.

### מודלים שלא ברשימה

**מתוך התוכנה:** בחלון "הורדת מודלים", בלשונית **קישור משלכם**, מדביקים קישור לקובץ מ-Hugging Face (גם קישור רגיל לדף הקובץ עובד).

**ידנית:** שמים את הקובץ בתיקייה:
- מודל שיחה: קובץ `.gguf` בתיקייה `מודלים`. אם יש לו קובץ `mmproj`, שמים את שניהם בתת-תיקייה משלהם.
- מודל תמונות: קובץ `.safetensors`, `.gguf` או `.ckpt` בתיקייה `מודלים\תמונות`.
- מודל תמונות שמגיע בכמה קבצים (FLUX, SD3, Z-Image): כל הקבצים בתת-תיקייה אחת בתוך `מודלים\תמונות`. התוכנה מזהה לפי השם את ה-VAE (`vae`/`ae`) ואת מקודדי הטקסט (`clip_l`, `t5xxl`, `qwen`...).

### סינון אינטרנט (נטפרי וכו')

אם הסינון חוסם את Hugging Face, ההורדה תיכשל עם הודעה מתאימה. אפשרויות:
- להגדיר **פרוקסי להורדות** בהגדרות (למשל `http://127.0.0.1:10809`)
- לבקש מהסינון לפתוח את האתר
- להוריד את הקובץ במחשב אחר ולהעתיק אותו לתיקיית המודלים

## בנייה מהקוד

הקוד הוא C# (‏.NET Framework 4.8, שמותקן בכל Windows 10/11) וממשק HTML/JS:

```
dotnet build src/LocalChat.csproj -c Release -o out
```

ה-workflow בתיקייה `.github/workflows` בונה את החבילה המלאה עם גרסאות נעוצות של
[llama.cpp](https://github.com/ggml-org/llama.cpp) ושל
[stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp).
רשימת המודלים להורדה נמצאת ב-`ui/catalog.json`, והתוכנה מושכת את הגרסה העדכנית שלה מהריפו.
