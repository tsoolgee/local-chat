# צ'אט מקומי

צ'אט בסגנון ChatGPT שרץ כולו אצלכם במחשב, בלי אינטרנט ובלי כרטיס גרפי.
שמים קובץ מודל בתיקייה `מודלים`, פותחים את התוכנה ומדברים. אפשר גם ליצור תמונות.

## מה יש בפנים

- ממשק מודרני בעברית: שיחות שנשמרות, חיפוש, הצמדה, שינוי שם, מצב כהה/בהיר
- תשובות שמופיעות תוך כדי כתיבה, עם Markdown, טבלאות והדגשת קוד
- עצירה, תשובה חדשה, עריכת הודעה ושליחה מחדש, העתקה
- תצוגת "מחשבות" למודלים חושבים (Qwen3, DeepSeek-R1 וכדומה)
- צירוף תמונות למודלים שרואים תמונות (כשיש קובץ mmproj ליד המודל)
- **יצירת תמונות** עם Stable Diffusion, SDXL, SD-Turbo, FLUX ועוד. תיאור בעברית מתורגם אוטומטית לאנגלית בעזרת מודל השיחה
- נייד לגמרי: השיחות, ההגדרות והתמונות נשמרים בתיקייה `נתונים` שליד התוכנה

## התקנה

1. מורידים את `LocalChat-win-x64.zip` מדף ה-[Releases](../../releases/latest) ופורסים לתיקייה.
2. שמים מודל שיחה (`.gguf`) בתיקייה `מודלים`.
3. (לא חובה) שמים מודל תמונות בתיקייה `מודלים\תמונות`.
4. מפעילים את `LocalChat.exe`.

הצ'אט נפתח בחלון משלו (דרך Edge או Chrome שכבר מותקנים). סגירת החלון סוגרת את התוכנה ומשחררת את הזיכרון.
כשהתוכנה רצה יש לה אייקון ליד השעון.

```
LocalChat\
├─ LocalChat.exe
├─ engine\            מנוע השיחה (llama.cpp) ומנוע התמונות (stable-diffusion.cpp)
├─ מודלים\
│  ├─ my-model-Q4_K_M.gguf
│  └─ תמונות\
│     └─ sd_turbo.safetensors
└─ נתונים\            נוצר אוטומטית: שיחות, הגדרות, תמונות
```

## איזה מודל לבחור

עם 32GB זיכרון ובלי כרטיס גרפי, הכי טוב לבחור מודלים בגרסה `Q4_K_M` (מחפשים ב-Hugging Face את שם המודל עם המילה GGUF):

| מודל | גודל | הערה |
| --- | --- | --- |
| Qwen3 8B | כ-5GB | מהיר וחכם, מאזן טוב |
| Gemma 3 12B | כ-7GB | עברית טובה, איטי יותר |
| Gemma 3 4B | כ-3GB | קטן ומהיר |
| DictaLM | משתנה | מודל עברי של דיקטה |

למודלי תמונות על מעבד מומלץ להתחיל ב-**SD-Turbo** או **SDXL-Turbo**: מספיקים להם 1 עד 4 צעדים.

מודל שמגיע בכמה קבצים (FLUX, SD3, Z-Image) נכנס לתת-תיקייה משלו בתוך `מודלים\תמונות`, עם כל הקבצים שלו (VAE, clip, t5 וכו'). התוכנה מזהה אותם לפי השם.

## הגדרות

- **גודל הקשר**: כמה מהשיחה המודל "זוכר". ברירת המחדל היא 8,192. ערך גבוה יותר צורך יותר זיכרון.
- **ליבות מעבד**: 0 בוחר אוטומטית.
- **הנחיית מערכת**, יצירתיות (temperature), אורך תשובה ועוד.

## בנייה מהקוד

הקוד הוא C# (‏.NET Framework 4.8, שמותקן בכל Windows 10/11) וממשק HTML/JS:

```
dotnet build src/LocalChat.csproj -c Release -o out
```

ה-workflow בתיקייה `.github/workflows` בונה את החבילה המלאה עם גרסאות נעוצות של
[llama.cpp](https://github.com/ggml-org/llama.cpp) ושל
[stable-diffusion.cpp](https://github.com/leejet/stable-diffusion.cpp).
